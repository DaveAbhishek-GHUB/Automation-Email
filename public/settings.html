Public App URL (for Gmail Tracking)
Gmail users can't reach localhost. Set a public URL here so tracking links in emails work for all recipients including Gmail users. Use ngrok or deploy to a server.
To get a free ngrok URL: open Terminal → run brew install ngrok → run ngrok http 3000 → paste the https URL above
Brevo API Key ★ RECOMMENDED for Railway
Bypasses Railway's SMTP block. Uses HTTPS (port 443) — always works. Free plan: 300 emails/day. Get your key at app.brevo.com → Settings → API Keys.
In Brevo: Profile → SMTP & API → API Keys tab → Create a new API key

CSV Format Guide

Your CSV must have an email column. Other columns are optional.

name email company phone city designation
Rahul Sharma rahul@example.com Acme Ltd 9876543210 Mumbai Manager
Priya Patel priya@gmail.com StartupXYZ 9988776655 Bangalore Founder
In emails, use {{name}}, {{email}}, {{company}}, {{phone}}, {{city}}, {{designation}} as variables.
